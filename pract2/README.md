# Визуализатор графа зависимостей пакетов (.NET / NuGet)

Инструмент командной строки для анализа и построения графа зависимостей пакетов с учётом транзитивности. Разработан в рамках практической работы №1 по дисциплине «Конфигурационное управление».

## Требования к оформлению репозитория
Проект спроектирован без использования сторонних зависимостей. Все модули и структура строго соответствуют стандарту PEP 8:
* Исходный код вынесен в изолированный пакет `src/`.
* Автоматические тесты находятся в пакете `tests/` и работают на базе встроенного фреймворка `unittest`.
* Ограничение длины строк составляет менее 80 символов.
* Отсутствуют бинарные файлы и архивы в коммитах.

## Инструкция по запуску проекта

### Запуск программы
Для выполнения анализа зависимостей на основе конфигурационного файла передайте путь к нему в качестве аргумента модуля:
```bash
python -m src.main config.json
```

### Запуск автоматических тестов
Для валидации корректности алгоритма DFS и парсеров запустите встроенный модуль тестирования:
```bash
python -m unittest discover -s tests
```
